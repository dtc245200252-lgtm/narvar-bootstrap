# Tạo Navbar với Bootstrap

Bài thực hành xây dựng thanh điều hướng (Navbar) chuyên nghiệp và responsive với Bootstrap 5.

## Mục tiêu
- Sử dụng Bootstrap qua CDN (`CSS` và `JS Bundle`).
- Tạo thanh điều hướng Navbar với thương hiệu `navbar-brand`.
- Hỗ trợ menu điều hướng với dropdown `Services`.
- Tự động co giãn responsive với nút thu gọn `navbar-toggler` trên thiết bị di động.

## Cấu trúc thư mục
- `index.html`: Chứa cấu trúc HTML và các class của Bootstrap Navbar.
